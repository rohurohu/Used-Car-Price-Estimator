Academic Project Documentation

Course Presentation & Methodology

Comprehensive documentation of the Machine Learning course project at KLH University.

Problem Statement Addressed
01

No Standard Valuation

Sellers overprice and buyers underbid, since there is no consistent, data-driven reference price in the pre-owned market.

02

Too Many Interacting Variables

Age, mileage, brand prestige, fuel type, transmission, and ownership history interact non-linearly with depreciation.

03

Manual Appraisal is Slow & Costly

Dealership or manual expert appraisal takes days, incurs expenses, and fails to scale to digital marketplaces.

04

Risk of Fraud & Mispricing

Buyers risk being misled by inflated listings, while private sellers unknowingly undersell high-demand vehicles.

6 Proposed Functionalities (Implemented)
1
Data Ingestion & Cleaning

Import datasets, drop duplicates, impute missing values, and handle statistical outliers.

2
Feature Engineering

Derive vehicle age, mileage/year intensity, power-to-engine ratio, and encode categorical variables.

3
Model Training & Benchmarking

Train and compare Linear Regression, Random Forest, and Gradient Boosting regressors.

4
Price Prediction REST API

Serve best regression pipeline via a fast REST endpoint with sub-second response times.

5
Interactive Web UI

Sleek, responsive web interface with auto-fill specs, presets, and instant appraisal feedback.

6
Evaluation Dashboard

Interactive charts displaying R², MAE, RMSE metrics and feature importance explainability.
